# Maa Kamakhya Jewellery website

This project adapts the supplied Grad Squad Pro / `durga` Next.js repository into a mobile-friendly jewellery showroom and catalogue for Maa Kamakhya Jewellery.

## Features
- Luxury black-and-gold visual direction
- Responsive mobile navigation
- Jewellery categories and client-side search
- Product enquiry list (not a payment cart)
- WhatsApp product and general enquiries
- Price-on-request presentation
- Showroom address and map search link

## Orders
This is an enquiry-based catalogue. It does not accept online payments or claim to reserve stock. The enquiry list sends product names to WhatsApp for staff confirmation.
